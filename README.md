# Our Table — Family Meal Planner

This is the first working prototype of the family meal planner.

## Current prototype
- Mobile-first weekly meal plan
- Meal library
- Add/edit/delete meals
- Structured ingredients
- Recipe links
- Favorites
- Grocery list generated from the week's meals
- Manual grocery items
- Pantry inventory
- Basic meal history
- Local persistence for prototype testing

## Next step
For multi-device family sharing, replace localStorage persistence with a hosted shared database such as Supabase (free tier). The UI/data model is intentionally structured so that can be added next.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

This prototype is intentionally dependency-free so it can be tested immediately.
